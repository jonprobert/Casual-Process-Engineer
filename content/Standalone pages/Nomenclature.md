# Nomenclature

## Symbology

The following is a list of symbology used throughout this guide. Units are SI unless otherwise specified.

| Description | Symbol | Unit |
| ---- | ---- | ---- |
| Density | $\rho$ | $kg/m^3$ |
| Entropy change of vapourisation | $\Delta S_{vap}$ | $J mol^{-1}K^{-1}$ |
| Ideal gas constant | $R$ | 8.314 $J K^{-1} mol^{-1}$ |
| [[Latent heat]] | $\Delta H_{vap}$ | $kJ/kg$ |
